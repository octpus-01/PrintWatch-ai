# 四、关键现象分析
1. 收敛速度梯队
第一梯队（极速收敛）：YOLOv26_Nano、PP_LCNet_PicoDet、ResNet18_SimAM、ResNet18_CBAM
Epoch1~2 即可达到 99%+ 甚至 100% 精度
第二梯队（平稳收敛）：ConvNeXt_Tiny、EdgeNeXt_YOLOv8、EfficientNet_Lite0
第三梯队（收敛差）：Res2Net_YOLOv7_Tiny、RepVGG_YOLOv6s
2. 过拟合 / 震荡问题
RepVGG_YOLOv6s：测试 Acc 剧烈震荡，Epoch1 直接掉到 62.5%，典型过拟合 + 鲁棒性差
EdgeNeXt_YOLOv8：中间 Epoch4 Acc 跌到 75.96%，数据泛化不足
Res2Net_YOLOv7_Tiny：全程精度最低，后期持续下降，模型适配性最差
其余满分模型：Loss 持续走低、测试 Acc 稳定无跳水，无明显过拟合
3. 数据集特性推断
所有优质模型仅需 2~6 个 Epoch 即可收敛到 100%，说明：
该 5 类缺陷数据集区分度高、样本特征差异明显
小模型、轻量骨干完全足以拟合任务，无需大模型
# 五、模型优选推荐
首选（兼顾精度、速度、轻量化、稳定性）
YOLOv26_Nano_End_to_End：最快收敛、100% 精度、极简轻量，适合部署
PP_LCNet_PicoDet：轻量检测架构，全程稳定满分，工业部署优选
ResNet_18_SimAM：精度 99.68%、全程几乎无波动，泛化能力最强
次选
ConvNeXt_Tiny_YOLOv26_Head、ResNet_18_CBAM、EdgeNeXt_YOLOv8、EfficientNet_Lite0_RetinaNet
不推荐
RepVGG_YOLOv6s（震荡严重）、Res2Net_YOLOv7_Tiny（精度低、泛化差）
# 六、后续优化建议
